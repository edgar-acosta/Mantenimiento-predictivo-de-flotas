## Daimler Fleet Maintenance Platform Plan
- [x] Set up a persistent database for five isolated client fleets, users, synthetic telemetry and maintenance records, warranties, evidence, claims, and service orders. Use a restrained fleet-operations design: off-white and charcoal surfaces, safety-amber and teal accents, clear sans-serif typography, dense but readable responsive layouts, Spanish/English text, and light/dark themes.
- [x] Build email/password sign-in with client-scoped access and network-administrator oversight, plus a client summary with active units, high-risk units, overdue services, monthly cost, priority actions, and risk trend; let the administrator switch client context and view network-wide figures.
- [x] Build searchable fleet and unit detail views with health by system, telemetry and fault codes, history and photo/video evidence, warranty status, and 30/90-day component failure probabilities from a trained synthetic-data model; turn risks into timed, costed, warranty-aware recommendations that can create service orders.
- [x] Build warranty management with coverage and claims, and a service-order workspace with a calendar, status board, parts tracking, and saved progress; apply language and theme controls throughout.
